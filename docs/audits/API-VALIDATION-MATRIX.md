# API Route Validation & Security Controls Matrix

| Route | Method | Auth Check | Authorization Check | Rate Limit | Input Validation | Body Size Limit | Notes |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| `/api/auth/oauth/[provider]` | GET | None (OAuth start) | None (Public redirect initiator) | IP Rate Limit (via middleware/edge) | Zod schema on `provider` enum (`google`, `github`) and `next` param | N/A (GET) | Sets PKCE cookie and initiates Supabase OAuth redirect. |
| `/api/auth/roles` | GET | Supabase session (Cookie / Bearer) | Resolves user's owned workspaces & bound clients | None | None (no request input) | N/A (GET) | Resolves dual-role status (freelancer workspace owner vs client portal). Cached with `no-store`. |
| `/api/email` | POST | Supabase session (Cookie / Bearer, or demo mock) | Server-side recipient resolution: client in caller's workspace, workspace owner, or self | IP & User rate limit (`EMAIL_DISPATCH`: 5 req/min) | Zod strict object (`EmailDispatchSchema`) | 100 KB | Dispatches transactional emails. Rejects unmapped recipients, unknown payload keys, and oversized HTML. |
| `/api/invitations/[token]/claim` | POST | Supabase session (Cookie / Bearer, or demo mock) | Token-based claim: single-use, binds client record to authenticated user | IP & User rate limit (`INVITATION_CLAIM`: 5 req/15min) | Zod token format check (`TokenParamSchema`) | 2 KB | Atomically binds client record to authenticated user account. |
| `/api/invitations/[token]` | GET | None (Public connection portal) | None (Returns non-sensitive public metadata only) | IP Rate Limit (`INVITATION_CLAIM`: 5 req/15min) | Zod token format check (`TokenParamSchema`) | N/A (GET) | Never leaks internal IDs (`client_id`, `workspace_id`, `freelancer_id`). |
| `/api/invoices/[invoiceId]/payment-status` | GET | `requireApiCaller()` session | Caller must own invoice as client (`client_id`) or freelancer (`workspace_id`) | IP Rate Limit | Zod UUID format check on `invoiceId` | N/A (GET) | Financial status lookup. `Cache-Control: no-store` enforced. |
| `/api/payments/[paymentId]` | GET | `requireApiCaller()` session | Caller must own invoice related to payment record | IP Rate Limit | Zod UUID / Gateway payment ID check | N/A (GET) | Resolves payment and receipt metadata. PostgREST filter injection neutralized. |
| `/api/payments/razorpay/order` | POST | `requireApiCaller()` session | Client/Workspace ID resolved authoritatively from caller session | IP & User rate limit (`PAYMENT_ORDER`: 10 req/min) | Zod strict object (`CreatePaymentOrderSchema`) | 10 KB | Creates server-side Razorpay order. Rejects unknown keys and invalid amounts. |
| `/api/payments/razorpay/verify` | POST | `requireApiCaller()` session | Client ID resolved authoritatively from caller session | IP & User rate limit (`PAYMENT_VERIFY`: 10 req/min) | Zod strict object (`VerifyPaymentSchema`) | 10 KB | Validates HMAC-SHA256 signature and captures payment. Rejects unknown keys. |
| `/api/webhooks/brevo` | POST | Secret token (`BREVO_WEBHOOK_SECRET` timing-safe) | Secret header authentication | IP Rate Limit (Webhook) | Zod schema on Brevo event types & message ID | 50 KB | Ingests Brevo email events. Fails closed if secret is unconfigured. |
| `/api/webhooks/razorpay` | POST | HMAC-SHA256 signature (`RAZORPAY_WEBHOOK_SECRET`) | Signature verification over raw request body | IP Rate Limit (Webhook) | Zod schema on Razorpay event structure | 100 KB | Authoritative payment status sync. Fails closed if signature is invalid. |
| `/api/webhooks/resend` | POST | Svix HMAC-SHA256 signature (`RESEND_WEBHOOK_SECRET`) with 5m tolerance | Svix signature verification over raw request body | IP Rate Limit (Webhook) | Zod schema on Resend event structure | 50 KB | Ingests Resend email events. Replays rejected (>300s window). |
| `/api/csp-report` | POST | None (Browser telemetry endpoint) | None | IP Rate Limit (30 req/min) | Zod strict object (`CspReportSchema`) | 10 KB | Logs CSP violations (directive, blocked URI). Strips PII and query strings. |
