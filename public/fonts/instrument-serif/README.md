# Instrument Serif Font Assets Directory

FlowDesk is configured with **Instrument Serif** as the primary typeface across the entire SaaS application (landing page, authenticated dashboard, client portal, navigation, settings, modals, and invoices).

Local font files provided:
- `InstrumentSerif-Regular.ttf` (400 normal)
- `InstrumentSerif-Italic.ttf` (400 italic)
